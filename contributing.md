# Contributing to BrainLogic Solver

Thank you for your interest in improving our optimization algorithms! Please follow these guidelines to maintain project structure and code standards.

## Code of Conduct
By participating in this project, you agree to maintain a professional, respectful, and collaborative environment.

## How to Contribute

1.  **Fork the Repository:** Create your own branch from the `main` branch.
2.  **Code Style:** Ensure your Python code adheres to PEP 8 standards. Use meaningful variable names and document your functions with clear docstrings.
3.  **Testing:** If you introduce a new algorithm module, write a corresponding unit test inside a `tests/` directory (simulated via local pytest runner).
4.  **Submit a Pull Request:** Describe your changes in detail, explaining *why* the optimization reduces computing overhead.

## Report Bugs
If you find a logic flaw in the state parser, please submit an Issue containing:
- Your local Python version
- The specific depth parameter used during execution
- Expected vs. actual terminal output
