# BrainLogic Solver Tool & Optimizer

Welcome to **BrainLogic Solver**, an open-source Python utility designed to analyze, parse, and benchmark logical puzzle structures found in modern mobile brain-teasers and riddle-based applications.

This repository contains core algorithm prototypes to evaluate graph-based decision trees and state-machine problems often used in mobile puzzle development.

## Features

- **Puzzle State Parser:** Convert visual/textual puzzle matrices into readable JSON structures.
- **Backtracking Solver Engine:** Automated recursive depth-first search (DFS) to find optimal steps.
- **Performance Benchmarking:** Analyze CPU execution time and memory footprint for complex dynamic riddles.
